# Vicu 2.8.0 for Android and iOS

**Supporting Vicu.** A couple of you have asked how you can support Vicu, so there is now a page for it: [ko-fi.com/rendyhd](https://ko-fi.com/rendyhd). I build Vicu in my evenings, next to a full-time job and a young family. I made it because I wanted it myself, and I still use it every day. There are no ads, no Vicu account and nothing behind a paywall, and that won't change. I truly appreciate the gesture: every tip, big or small, tells me this work matters to someone. Thank you.

Vicu 2.8.0 brings Vikunja's saved filters into Vicu, turns Markdown into formatted notes, keeps files you add offline, and makes it easier to move a plan to another day. Update the desktop app to 2.8.0 too, so both apps read saved filters, list rules and planner moves the same way.

### New

- **Saved filters.** Vikunja's saved filters showed up as empty projects. They now become custom lists: Vicu imports every saved filter it can read the first time it syncs your lists, and Settings, Projects, Custom Lists offers new ones and has **Import saved filters**. An import is a copy, which the list says once, and two devices never import the same filter twice. ([#103](https://github.com/rendyhd/Vicu-Mobile/issues/103))
- **Rules in custom lists.** A custom list can have a rule in Vikunja's filter syntax, such as `done = false && priority > 2`, next to its other conditions. The editor shows label and project names, suggests fields, operators and values, and keeps Save off until the rule reads.
- **Then by.** A custom list can sort by a second field, and the orders are named for the field, such as "Soonest first" and "A to Z".
- **Markdown in notes.** Markdown you paste into the notes becomes formatting, and typing Markdown formats as you go: headings, quotes, lists, `[ ]` checklists, code, dividers, bold, italic, strikethrough and `[text](url)` links. Notes are still saved as Vikunja's HTML. On iOS pasted Markdown stays plain text for now; typing works on both.
- **Planner: another day.** A block can move to another day: drop it on a day in the week strip, rest it on a day while you drag, tap a day with a second finger, or pick the day in the block's sheet. Swipe the timeline sideways for the next or previous day, and the strip for a week. A row above the hours shows the day's tasks without a time; drop a block there to take its time away. A move that changes the due date says so, with Undo. ([#101](https://github.com/rendyhd/Vicu-Mobile/issues/101))
- **Open a duplicate.** After Duplicate, the message has Open for a single copy and Undo for any number; Undo deletes the copies and their subtasks. ([#97](https://github.com/rendyhd/Vicu-Mobile/issues/97))

### Fixes

- **Files added offline.** A file or image added while the server cannot be reached, or to a task created offline, was accepted and then lost. It now waits on the phone and uploads once the server is back, and images land at the end of the notes. The editor shows waiting files with Remove, and a refused file says why and offers Retry. Quick add and Android's share sheet do the same and say how many files upload later. ([#104](https://github.com/rendyhd/Vicu-Mobile/issues/104))
- **Typing a time.** Editing the time of a date such as "Today, Oct 8, 1:00 PM" by hand and pressing Done no longer clears the date and time. ([#98](https://github.com/rendyhd/Vicu-Mobile/issues/98))
- **Reminders at due time.** A reminder set relative to the due date now follows the date when you change it, instead of counting from the old one. ([#99](https://github.com/rendyhd/Vicu-Mobile/issues/99))
- **Notes in quick add.** One tap on Notes puts the cursor in the notes, so you can keep typing. ([#100](https://github.com/rendyhd/Vicu-Mobile/issues/100))
- **Times with dots.** Quick add reads "3 p.m." and "9 a.m." as times, as the desktop does.
