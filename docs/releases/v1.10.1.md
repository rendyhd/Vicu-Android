# Vicu Android 1.10.1

Vicu Android 1.10.1 ships together with Vicu 1.10.1 for the desktop. Projects get their own tab in Settings, and you can manage a project from its screen and add one from the drawer.

This is a pre-release that builds on 1.10.0. If you find a rough edge, please [open an issue](https://github.com/rendyhd/Vicu-Android/issues).

### Projects in Settings

- **Settings** has four tabs: **General**, **Projects**, **Notifications** and **Gestures**. On a narrow screen the tab row scrolls.
- **Projects** holds the Inbox choice, all your projects, display options, project review, labels and custom lists. General keeps the rest.
- Tap a project to edit it, or hold and drag it to change its order within its level; TalkBack offers Move up and Move down. The **⋮** menu on each row has **Edit**, **Add subproject**, **Set as Inbox**, **Archive** and **Delete**.
- Archived projects are in a collapsed **Archived** group with **Restore**, instead of a switch that showed them in the list.
- Projects are listed in the same order as in the drawer.
- Project review has an **Excluded from review** list where you can include a project again.
- New setting **Show project progress** (on by default, under Projects, Display): turn it off to hide the progress rings in the drawer.

### Manage a project from its screen

- A project's screen has a **⋮** menu: **Edit project**, **Add subproject**, **Set as Inbox**, **Mark reviewed** (with Undo), **Archive** and **Delete**.
- The **Projects** header in the drawer has a **+** to add a project.

### Fixes

- The widgets use the same colours as the app: the Vicu colours, or your wallpaper colours when **Use device colours** is on. Before, some launchers drew the widgets' secondary text, checkbox outlines and + with almost no contrast.
- Switching between the main screens is a plain fade, without the zoom.

### Known issues

- The calendar in the When sheet starts the week on Sunday; the rest of Vicu, and the desktop app, start on Monday.
- Undo of a repeating task that was completed while offline does not put its dates back.

### Upgrade notes

- The Inbox choice, project review, labels and custom lists moved from **General** to the new **Projects** tab. Your settings carry over.
- Update both apps to 1.10.1 to get the same project actions on both.
- Vicu Android needs a Vikunja server running version 2.4.0 or newer.
