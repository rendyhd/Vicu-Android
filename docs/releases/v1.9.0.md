# Vicu Android 1.9.0

Vicu Android 1.9.0 ships together with Vicu 1.9.0 for the desktop. Both apps now read your synced data the same way, work you do offline is no longer lost, reminders follow your tasks more reliably, and a long list of bugs is fixed.

### The same data means the same thing on desktop and Android

- Custom lists use the same date windows on both apps, with a new **Include overdue tasks** option for the Today, This week, and This month windows (on by default, as before). Lists also sort the same way, with tasks that have no date last in both directions, and the editor offers more sorts.
- A due date without a time is stored at the end of that day and shown without a time. A date with a time keeps its time, shown in your phone's 12 or 24 hour style. Older dates saved at midnight show as date-only, and the year is shown when the date is not in this year.
- Today ends at the start of your local tomorrow and has an Overdue section above it. Today, Upcoming, and Overdue follow your local calendar day, and lists move on at midnight, after the phone wakes up, and when the date, time, or time zone changes. The widget and the daily summary use the same boundary.
- Project review status is calculated the same way on both.
- Quick-add parsing follows one shared set of rules: `!med` and `!critical`, a leading or trailing `!` for today, phrases like `friday 3pm`, `in 2 hours`, and `every Monday`, and `biweekly`. A weekday right before another date stays in the title ("Call Ana about Saturday tomorrow at 3pm" is due tomorrow at 3 PM), and `friday next week` means next Friday.

### Your work is no longer lost

- Changes you made offline are kept when you sign in again, sign out, or clear the cache. They are only dropped when you choose to discard them, and the dialogs show how many are waiting. Local data is only cleared when you sign in to a different server or as a different user.
- A mistyped API token no longer signs you out.
- Only one sync runs at a time, which ends the duplicate tasks and duplicate deletes that two overlapping syncs could cause.
- Changes the server refuses show in a banner with **Retry** and **Discard**, and are dropped after 14 days. A change to something deleted on the server no longer stays stuck in the queue. When your session needs a new sign-in, sync pauses and keeps everything until you do.
- Renaming, archiving, or moving a project, and marking a project review, now work offline like task edits and are sent when the connection is back.
- Vicu sends only the fields you changed. Editing a task on your phone no longer reverts something you changed on your PC a moment earlier, and swiping a task to schedule it changes only its due date.
- Task edits are saved as you type and survive the app being closed by the system.
- A subtask you create offline is stored under its parent and linked when you are back online.
- A change to a task that still has an older change waiting is queued behind it, so the older one can no longer overwrite your latest edit or undo when it is sent.
- Waiting changes are sent within seconds of the connection coming back, and are retried for as long as the server is unreachable instead of being given up after five tries.
- Mark Complete in a notification or on a widget is stored at once, so it is not lost when Android closes the app before it reaches the server.
- The sign-out warning also counts custom-list changes that have not synced yet.
- Saving a change the server already has (the same title, a task that is already open) no longer shows as a change that could not be synced.

### Reminders and notifications

- No more ghost reminders. A reminder for a task you completed, deleted, or removed the reminder from on another device is cancelled, and a notification only appears when the task is still open and still has that reminder.
- **Mark Complete** in a notification never reopens a task that is already done.
- "1 hour before" and the other relative reminders count from the date they name.
- Vicu now syncs in the background every 30 minutes, so a task or reminder you changed elsewhere reaches your phone while the app is closed. Reminders and widgets update with it.
- The daily summary arrives at the time you set, also across daylight saving changes. It counts overdue, due today, and due tomorrow like the desktop app, and the option is called **Include Tomorrow**. If a summary was lost to a data clear or a system cleanup, it is queued again when you open the app.
- Reminders for tasks created offline are scheduled right away.

### Routine history on your server

A routine keeps its last 400 days of history. Older history moves to hidden archive tasks on your Vikunja server (titled "Vicu routine archive", marked done) and stays available in the history view and the CSV export. You may see these tasks in other Vikunja apps; leave them in place.

Routine history that older versions kept only on this phone is uploaded to the server once, in the background, as soon as the phone can reach it. Signing out only warns about history that has not been uploaded yet. Routines merge by the same rules as on the desktop, and the CSV export protects cells that a spreadsheet would run as formulas.

### Attachments

- Open or share any file from a task, not only images.
- Uploads and downloads stream, so large files no longer fill the phone's memory, and the server's file size limit is checked before an upload starts.
- Deleting an attachment asks first, and is rolled back if the server refuses.

### Inbox, search, and the task editor

- The Inbox lists tasks with a date first and the rest in the order of the Inbox project on the server. Long-press and drag a task to put it where you want; the new order shows on the desktop too.
- Search shows matches from your phone at once and looks in titles and descriptions. Completed tasks are in a section of their own, and the server is asked in the background.
- The task editor shows the current due date, project, priority, repeat, and reminders under the icons, has a done checkbox next to the title, keeps titles on one line, and opens a subtask when you tap it.
- The pickers open on the value being edited, the project picker is searchable, and the image viewer zooms around your fingers.
- Sign-in remembers the server address when you sign in again, Back steps through the setup, the form scrolls above the keyboard, the API token and password are hidden behind a show toggle, and an `http://` address outside your own network shows a warning.

### Accessibility

- Task rows work with TalkBack: the checkbox is named after the task, rows offer Complete, Due today, and Due tomorrow as actions, priority is read out, and sections announce whether they are expanded.
- Every list you can reorder has **Move up** and **Move down** actions, and small controls now have full-size touch targets.

### Fixes

- Collapsed project sections stay collapsed when you come back to the screen.
- Anytime shows every project level. The Tag and custom list views filter before nested subtasks are hidden.
- A completed task stays where it is through a screen rotation, and an add or share does not reopen itself after a rotation.
- A share is kept when the screen rotates, and the start screen no longer flashes the Inbox before sign-in.
- The Inbox says so when no Inbox project is selected, and follows the project you pick.
- Custom lists never ask the server for a sort it rejects, and the widget reads a custom list from the same tasks as the screen.
- Project review shows refused changes instead of hiding them, and expanded rows follow their tasks.
- Choosing the screen that is already open only closes the drawer instead of rebuilding it.
- Failures to refresh a list are shown on the list, and lists refresh after you sign in.
- The date chip under the quick-add field names the day the way your task list does ("Sat", "Oct 20") instead of showing "2026-10-10".

### Faster

- Task lists refresh only what changed, and the Logbook loads older tasks on request.
- Custom lists and routines find their stored data directly instead of paging through every completed task.
- A new task appears at once; its place at the end of the list is set in the background.
- The project drawer and the task lists draw less work per row, so scrolling is smoother on large accounts.

### Privacy and security

- Release builds no longer log requests or debug output.
- Backups and device transfer now leave out the task database, your sign-in tokens, and local state such as alarms and widget settings. The old rules named the wrong database file, so a restore could bring back stale queued changes.
- Signing out revokes the backup API token that Vicu created for your phone, and two phones of the same model no longer delete each other's backup tokens.
- A failed sign-in refresh caused by a network problem is no longer treated like a server error, and Vicu waits longer between attempts when the server asks it to slow down.

### Upgrade notes

- Update both apps to 1.9.0.
- Vicu Android needs a Vikunja server running version 2.4.0 or newer.
- Open the app once while connected after updating, so the routine history that was kept only on your phone can be uploaded to the server.
- Until both apps are updated, an older version may briefly show different custom-list results and can bring back archived routine history entries, which the new version removes again.
- Reminders set up by an older version are replaced the next time reminders are rescheduled, and are checked again when they fire, so there is nothing to do.
