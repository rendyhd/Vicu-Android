# Vicu 2.6.3 for Android and iOS

Vicu 2.6.3 brings comments to every task, adds roomier task rows and lets you open a task right after adding it. The connection banner now says what is actually wrong. Update the desktop app to 2.6.3 too, so both apps agree on comments and custom lists.

### New

- **Comments on every task.** Comments no longer need a shared project. On a project nobody else can see they are notes to yourself, and the row shows their count. Assign, the unread mark, mentions and Notify me stay on shared projects. A custom list set to any comments now matches every project. ([#86](https://github.com/rendyhd/Vicu-Mobile/issues/86))
- **Comfortable task rows.** Settings, General, Appearance has **Task rows**. Compact stays the default. Comfortable shows up to three lines of title and a line of notes. ([#72](https://github.com/rendyhd/Vicu-Mobile/issues/72))
- **Open a task you just added.** The confirmation after adding a task has **Open** next to **Undo**, from quick add, holding the +, dictation and Ask. Quick add now confirms too, unless **Keep add-task open** is on. ([#80](https://github.com/rendyhd/Vicu-Mobile/issues/80), [#73](https://github.com/rendyhd/Vicu-Mobile/issues/73))
- **Clear a draft.** Quick add has an X that clears everything you entered. It turns into **Undo** until you type again. ([#81](https://github.com/rendyhd/Vicu-Mobile/issues/81))
- **Stop in Ask.** Send turns into **Stop** while the assistant works, and a stopped answer offers **Retry**. ([#79](https://github.com/rendyhd/Vicu-Mobile/issues/79))
- **Dates that say the day.** Date chips, in the task editor and in dictation's drafts among others, now give the word and the date for yesterday, today and tomorrow, such as "Today, 7 Oct". ([#76](https://github.com/rendyhd/Vicu-Mobile/issues/76), [#82](https://github.com/rendyhd/Vicu-Mobile/issues/82))

### Fixes

- **Connection banner.** The banner sits below the status bar in a neutral colour and says either **Offline** or **Can't reach the server**, with the number of changes waiting. When the server is back the banner goes and the changes are sent. Airplane mode now counts as offline while the app is running. ([#87](https://github.com/rendyhd/Vicu-Mobile/issues/87))
- **Label picker.** New label and Done share one row, and while you name a new label they make way for Cancel and Create, so Done cannot be pressed by mistake. A search without a match offers to create that label. The app now says Labels everywhere instead of Tags. ([#74](https://github.com/rendyhd/Vicu-Mobile/issues/74), [#85](https://github.com/rendyhd/Vicu-Mobile/issues/85))
- **Shared files.** A shared screenshot or file starts with an empty title instead of the name the sending app gave it. Text-only shares are unchanged.
- **Menus.** Menu items that open a picker or a dialog, such as Assign and Move to category, no longer end in dots.
