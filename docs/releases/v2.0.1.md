# Vicu Android 2.0.1

Vicu Android 2.0.1 ships together with Vicu 2.0.1 for the desktop. It stops Vicu from signing you out when an API token is not allowed to do something, and makes switching between the main screens one smooth fade again.

This is a pre-release that builds on 2.0.0; if you are coming from 1.10, read the [2.0.0 notes](https://github.com/rendyhd/Vicu-Android/releases/tag/v2.0.0) too. If you find a rough edge, please [open an issue](https://github.com/rendyhd/Vicu-Android/issues). The desktop side is in the [Vicu 2.0.1 notes](https://github.com/rendyhd/vicu/releases/tag/v2.0.1).

### Signed in with an API token

Vikunja lets you choose what an API token may do, and it answers a request the token is not allowed to make as if the session had ended. Vicu took that at its word and sent you to the sign-in screen.

- Opening the comments of a shared task, assigning someone, writing a comment or sharing a project with a token that lacks that permission no longer signs you out, and neither does the background check of who can see your projects. Vicu now says what the token is missing: give the token the permissions for task comments, task assignees and project sharing in Vikunja, or sign in with your password instead.
- A comment or assignment made offline that the token is not allowed to send is set aside as a failed change, and the rest of your offline changes are still sent. Before, it paused syncing until you signed in again.
- The **Notify me** bell on the Comments screen is only shown when you sign in with your password or single sign-on. Vikunja does not let API tokens follow tasks at all.

If you sign in with your password or single sign-on, nothing changes for you.

### Fixes

- Switching between the main screens is one smooth fade again. Before, going to the Inbox and back to Today could start the fade on an empty screen, stop half-way with both screens showing, and then jump into place. A screen now fades in once its tasks are there, and Today keeps its content when you come back to it.

### Known issues

- The calendar in the When sheet starts the week on Sunday; the rest of Vicu, and the desktop app, start on Monday.
- Undo of a repeating task that was completed while offline does not put its dates back.
